# feat: report template placeholder text left on a Japanese shop page

Fake shops are built from shared kits and often keep the kit's placeholders (docs/fake-shop-research.md, item 13).

- `shop_template_leftovers` (low) applies on a Japanese shop page. It looks for a company or shop name made of 〇 / ×, a phone number or postal code of zeros. English template wording (lorem ipsum, "your store name", "Default Store View") is not used, since real shops use it too.
- Evidence is the kind of placeholder only.
- Real numbers containing zeros and a single 〇 (〇月〇日) do not count.
